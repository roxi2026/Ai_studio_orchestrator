## 2025-07-22 - [Optimized Log Rendering & Network Interception]
**Learning:** Legacy extension UI re-rendered the entire log history in O(N) complexity using `innerHTML` on every state update, leading to substantial DOM reflows and browser rendering lag. Additionally, unconditional fetch interception in `inject.js` forced stream cloning and string buffer reading for every single host page request (including static assets and third-party telemetry), introducing severe overhead.
**Action:** Transition log rendering to O(1) incremental DOM updates using a monotonic state counter and `DocumentFragment` with `textContent` for batch appending. Restrict network interception to matching AI Studio API URLs (`generateContent`, `v1beta`, `executor`, `reviewer`) prior to response cloning or parsing to eliminate ~42.9% of redundant stream buffer processing overhead.
