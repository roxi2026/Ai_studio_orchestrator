## 2025-05-20 - Dual Extension Performance: Incremental Log Rendering and Target URL Interception Filtering
**Learning:** In Chrome Extension UI panels receiving frequent state updates over chrome.storage.local, innerHTML re-rendering of capped log arrays creates continuous O(N) DOM node destruction and string parsing. Using a monotonic state.totalLogs counter with DocumentFragment incremental appends reduces log update overhead by over 37x. Additionally, main-world fetch interceptors cloning response bodies for all domain traffic impose major CPU/memory overhead on static assets unless filtered by endpoint pattern prior to clone().
**Action:** Always pair fixed-size sliding-window state arrays with a monotonic sequence counter for O(1) incremental DOM updates, and enforce URL pattern filters on fetch/XHR interceptors before body cloning.
