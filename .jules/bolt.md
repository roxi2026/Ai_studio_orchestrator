## 2025-05-20 - DOM Extraction Reflows & Asset Download Waterfalls
**Learning:** In browser extension puppet scripts, reading `innerText` in DOM extraction loops (e.g. `GET_LINKS`, `EXTRACT_SPATIAL`, candidate scoring) triggers forced synchronous layout reflows (layout thrashing) on every element. Switching to `textContent` retrieves node text without triggering layout calculations. In client-side zip generation, sequential `await fetch` loops create network waterfalls that degrade user download speeds; `Promise.all` parallelizes asset retrieval cleanly.
**Action:** Always prefer `textContent` over `innerText` for non-layout text extractions in web scrapers/puppet scripts, hoist document string calculations outside scoring loops, and use `Promise.all` for multi-asset zip fetching.
